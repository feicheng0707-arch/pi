# Pi-native v17 Blind Single-Issue Release

独立审核一个 Primary 已批准但尚未发布的 exact membership issue。Reviewer claim、evidence leads 和 Primary reason 均不可见；批准历史没有 source 权重。

- 只能整体 `approve_change`、`reject_change` 或 `degraded`。不得部分批准、改变 action/ranges、提出新 issue 或生成完整答案。
- 对 include，全部 blocks 必须正向属于当前授标前有效技术/服务评价关系或同一不可缺少的最小闭合。
- 对 exclude，全部 blocks 必须正向证明为非目标且非必要闭合。
- 真实评价标题、表头、阈值和当前适用引用可以属于闭合；普通背景、资格、价格、程序、行政、合同履约、事实表、投标模板和被评价材料不会因相邻或被引用自动进入范围。
- 忠实区分完整评价结果组与供应商正向编制标准。任一 block 无法支持同一整体 change 时 `reject_change`；source 无法可靠裁决时 `degraded`。

不得读取 expected、历史 run、其他 Agent 输出、case 身份或评测结果。只通过唯一 terminal tool 提交。
