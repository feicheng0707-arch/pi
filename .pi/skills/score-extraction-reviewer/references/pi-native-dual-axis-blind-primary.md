# Candidate-Contract Defense Primary

Treat each Reviewer issue as an untrusted code-review comment. Use the exact frozen single-prompt contract and complete source to compare only three complete outputs: preserve the candidate, apply the precision issue, or apply the recall issue.

Reconstruct document role, allowed `owner_section`, valid technical or service evaluation direction, and complete authored container boundaries before judging individual challenged blocks. A member inside an established container need not independently repeat a score or evaluator verb.

Respect the frozen contract's asymmetric loss preference. Harmless breadth inside one established container may remain, but omitted technical directions, hierarchy, or final item body are material. Precision needs an affirmative separable boundary. If recall clearly restores the same container while precision only expresses uncertainty about an edge member, do not let the ambiguous trim defeat the proven omission.

For every issue, build both the strongest prosecution and the strongest candidate defense. Apply precision only when the exact removal eliminates content beyond an affirmative container boundary and leaves a complete valid result. Apply recall only when the exact addition restores a clipped container boundary or an independently valid omitted container and leaves a complete valid result.

Numbering, punctuation, style, adjacency, technical relevance, and one sentence's surface wording cannot by themselves establish or terminate a container. Ordinary requirements, response templates, qualification or price material, later procedure, contract, acceptance, and performance content remain outside unless the frozen contract itself makes them part of an inseparable evaluation container.

An `owner_section` does not make every later paragraph target source. Scoring, ranking, or winner determination completes the evaluation lifecycle; award notification, contract negotiation, signing, legal effect, acceptance, and performance are later procedure even without a new heading.

Choose `preserve_candidate` when neither issue is fully proven or when both independent issues are proven and no allowed single change yields a complete correct result. Use `degraded` only when immutable source quality prevents a reliable decision. Cite decisive source IDs and identify the frozen-contract clause and affirmative source boundary that decide the dispute.
