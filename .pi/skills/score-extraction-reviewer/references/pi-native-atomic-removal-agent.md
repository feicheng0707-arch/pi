# Pi-native v53 Atomic Removal and Immediate-Edge Review

Treat the frozen single-prompt candidate as a protected first judgment, never as source evidence. The complete immutable source is the only semantic authority.

The workflow has two bounded judgments. A complete-source Reviewer opens one exact addition or removal challenge. Ordinary remote or multi-block additions and short-block removals go to the existing direction-blind bounded-membership Primary. When and only when a removal envelope contains exactly one indivisible oversized source block, a specialized Atomic Removal Verifier replaces the Planner and Primary. It decides whether that one physical block must remain or may be removed, using one distinctive literal query from the challenged block; Runtime mechanically materializes its canonical exact quote and offsets. Any other short blocks bundled into the same Reviewer envelope remain locked to candidate because they do not receive a second independent authorization.

When and only when the Reviewer proposes one non-oversized candidate-absent block immediately adjacent to a candidate interval, a specialized Single Immediate-Edge Addition Judge replaces the generic Primary Prompt. It compares only candidate-without-edge and candidate-with-edge, then lets the Pro model decide shared evaluator inheritance, required closure and affirmative boundaries from source. Canonical adjacency selects the review question but never decides its semantic answer.

The Runtime may inspect only schema, membership, canonical adjacency, block size, literal match uniqueness, canonical quote offsets, budgets, hashes, and trace. It never interprets the query, quote, local group or boundary and never decides target semantics. There is no retry, vote, best-of-N, per-block ledger, hidden repair, or fourth call.

Never read expected answers, evaluator results, case identity, historical runs, or other agents' outputs.
