##评分方式主要分类和特征##：{"""


主要的评分方式场景：
评分方式	核心指标	技术 / 商务评审深度	评分构成（核心评分因素）	适用场景
1. 综合评分法	综合得分（多因素加权汇总）	深度量化打分（按预设权重打分）	报价 + 技术（方案 / 参数）+ 商务（资质 / 业绩）+ 服务（售后 / 质保）+ 其他（创新 / 节能等）	技术复杂、个性化需求项目（如软件开发、工程设计、定制服务）
2. 经评审的最低投标价法	最低合格报价（满足全部实质性要求）	仅符合性审查（不满足即淘汰，不打分）	仅报价（需先通过技术、商务实质性条款审查）	技术标准统一、通用性强项目（如通用设备采购、标准化工程施工）
3. 合理低价法	合理低价（防低于企业个别成本）	符合性审查 + 成本合理性分析（人工 / 材料 / 机械费测算）	报价（需通过技术符合性审查 + 成本合理性分析）	工程施工项目（平衡低价与质量风险，避免恶性竞争）
4. 性价比法	（非价格因素得分）÷ 投标报价	非价格因素量化打分（技术 / 商务 / 服务）	（技术 + 商务 + 服务等非价格因素得分）÷ 报价	服务类项目（强调 “单位价格的质量效率”，如物业服务、咨询服务）
5. 双信封评标法	技术合格 + 最低报价	技术信封（符合性审查或打分）→ 商务信封（报价评审）	技术（符合性审查或打分）+ 报价	大型工程施工（如公路、水利，技术与价格分离评审，先评技术后开价格）
6. 最低评标价法	修正后的最低评标价（含报价调整）	技术商务符合性审查 + 报价修正（算术错误、漏项、细微偏差折价）	修正后的报价（技术商务符合性审查 + 报价修正）	货物采购（需严格修正报价偏差，如小数点错误、漏报项目调整）
7. 固定价评审法	报价是否等于预设固定价	技术商务符合性审查	仅固定价（报价需等于招标人预设总价，否则淘汰）	抢险救灾、应急采购、小额零星项目（招标人预设总价，无价格竞争）
8. 评定分离方式	评标委员会确定符合的投标人，采购人决定最终中标人	报价、商务、技术进行符合性审查	大型工程施工（如公路、水利等，采用符合性审查，最终有采购人确定符合审查名单中的最终中标人）
9.其他总分值100分但不包含技术评分表特征的评分方式	报价、资格信用、商务等类型总分值100分	100分是评分表的满分，代表已经是全部评分类型，所以该类型并不存在具体的技术评分表	工程类型、询价、措施等类型中存在该类评分方式

其中一定不存在技术评分因素的评分方式：
1. 经评审的最低投标价法
技术因素处理方式：仅对技术部分进行 “实质性条款符合性审查”（如技术参数、资质、质量标准等是否满足招标文件要求），不满足则直接淘汰，不进行技术因素的量化打分。
核心逻辑：在所有 “技术合格” 的投标人中，仅比较投标报价，最低价者中标。
结论：技术因素无评分，仅作为 “合格性门槛”。
2. 合理低价法
技术因素处理方式：技术部分同样仅做 “符合性审查”（检查是否满足工程技术标准、工期、质量等实质性要求），不满足则淘汰，不涉及技术因素的量化打分。
核心逻辑：在技术合格的基础上，重点评审报价的 “合理性”（是否低于企业个别成本），而非技术优劣。
结论：技术因素无评分，仅作为 “合格性门槛”。
3. 最低评标价法
技术因素处理方式：技术部分仅进行 “符合性审查”（如货物技术参数、性能指标是否达标），不满足则淘汰，不进行技术打分。
核心逻辑：对通过技术符合性审查的投标报价进行修正（如算术错误调整、漏项补价等），以 “修正后的评标价” 最低者中标。
结论：技术因素无评分，仅作为 “合格性门槛”。
4. 固定价评审法
技术因素处理方式：技术部分仅做 “符合性审查”（检查是否满足项目技术要求、服务标准等），不满足则淘汰，不进行技术打分。
核心逻辑：招标人预设固定总价，投标人报价需等于固定价且技术合格，无价格竞争，仅通过技术合格性筛选。
结论：技术因素无评分，仅作为 “合格性门槛”。

##技术评分表特征##：{"""

技术评分表定义：场景一技术评分细则表  和  场景二技术评审规则表统称为技术评分表。

场景一：技术评分细则表
以下三个属性至少存在两个才是技术评分规则表。
1.评分项名称：对某一项评分的归纳名称，比如：项目整体实施方案、人员培训方案、服务承诺
2.得分标准：描述某一项评分的得分条件，比如：内容完整、具备可实施性和创新型得5分、内容完整、具备可实施性得3分
3.评分项分数：某一项评分的总分，比如：项目整体实施方案：满分3分、人员培训方案：满分5分

##技术方案内容构成评审项特征##：{"""

定义：招标文件中针对技术方案内具体内容模块设置的评审项目，是技术方案评审的基本单元。它围绕招标项目技术需求，将技术方案的内容模块细化为可独立评审的条目，如服务方案、实施方案、技术路线方案、质量保障方案等。格式类、封装类、签字盖章等非内容构成要求不属于技术方案评审项。

要求：要严格按照定义从原文提取，若原文不存在直接输出 null。
